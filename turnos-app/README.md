# Turnos — App completa para estilistas independientes

Proyecto full-stack: reservas + pagos para estilistas que trabajan por su cuenta.

```
turnos-app/
├── turnos-backend/     # API (Express + SQLite + Stripe) — ver su README para instalarla
└── turnos-frontend/    # Interfaz responsive/PWA que consume esa API — ver su README
```

## Orden para probarlo

1. Entra a `turnos-backend/`, sigue su README (`npm install`, configurar `.env`, `npm start`).
2. Entra a `turnos-frontend/`, abre `index.html` en el navegador (con el backend ya corriendo en `http://localhost:4000`).

Cada carpeta tiene su propio README con el detalle de endpoints, variables de entorno y próximos pasos sugeridos.
